# Pregnancy Vitals Tracker

##  Description
Pregnancy Vitals Tracker is an Android application that helps expectant mothers log and track important pregnancy-related vitals. The app allows users to add vitals, view historical records, and receive timely reminders to log their health data.

---

##  Tech Stack
- **Language:** Kotlin  
- **UI:** Jetpack Compose  
- **Architecture:** MVVM  
- **Database:** Room  
- **State Management:** StateFlow  
- **Background Tasks:** WorkManager  

---

##  Features
- Log pregnancy vitals (Blood Pressure, Heart Rate, Weight, Baby Kicks)
- View vitals history using LazyColumn
- Add vitals using a pop-up dialog
- Auto-update UI using StateFlow
- Reminder notification every 5 hours using WorkManager
- Notification opens the app directly

---


##  How to Run
1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle files
4. Run the app on an emulator or physical device
